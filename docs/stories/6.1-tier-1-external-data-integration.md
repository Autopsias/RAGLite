- Pydantic models for each source in `raglite/external_data/models.py`
- Modern type hints: `dict[str, Any]` (not `Dict[str, Any]`)
- Validate all responses before storage

### AC3: Error Handling

- Retry logic: 3 attempts with exponential backoff (1s, 2s, 4s)
- **Use existing pattern from `raglite/shared/clients.py` lines 111-171** (no `tenacity` dependency)
- Raise `ExternalDataFetchError` on permanent failure
- Structured logging via `raglite.shared.logging.get_logger`

### AC4: Fallback Strategy

- Cache API responses in PostgreSQL (Story 6.2)
- **Before Story 6.2:** Store in memory/JSON files for initial testing
- Stale data tolerance: 30 days max
- Log WARNING when using cached/stale data

### AC5: Historical Data Load

- Batch loading with progress logging
- Store in PostgreSQL `external_data_points` table (after Story 6.2)

### AC6: Unit Tests (80%+ coverage)

- Mock API responses using `unittest.mock` (AsyncMock/MagicMock)
- Test scenarios: success, timeout, invalid response, rate limit (429), auth failure (401)
- Each client file must have ≥80% individual coverage

### AC7: Integration Tests

### API Client Pattern

Follow the retry pattern from `raglite/shared/clients.py` (lines 111-171):

```python
"""External data client for INE API."""
from __future__ import annotations

from datetime import datetime
import httpx

from raglite.shared.config import settings
from raglite.shared.logging import get_logger
from raglite.external_data.models import INEBuildingPermits
from raglite.external_data.exceptions import ExternalDataFetchError

logger = get_logger(__name__)

# API Configuration
INE_API_BASE = "https://www.ine.pt/xportal/xmain"

class INEClient:
    """Client for INE (Instituto Nacional de Estatística) API."""

    def __init__(self):
        self.base_url = INE_API_BASE
        self.api_key = settings.ine_api_key
        # Use test timeout in test environment (per clients.py pattern)
        import os
        is_test = os.getenv("PYTEST_CURRENT_TEST") is not None
        self.timeout = 1.0 if is_test else float(settings.external_data_timeout)

    async def fetch_building_permits(
        self,
        start_date: datetime,
        end_date: datetime
    ) -> list[INEBuildingPermits]:
        """Fetch building permits with retry logic."""
        max_retries = settings.external_data_retry_attempts
        retry_delays = [1, 2, 4]  # Exponential backoff

        async with httpx.AsyncClient(timeout=self.timeout) as client:
            for attempt in range(max_retries):
                try:
                    response = await client.get(
                        self.base_url,
                        params={
                            "xpgid": "ine_api",
                            "xlang": "pt",
                            "start": start_date.strftime("%Y-%m-%d"),
                            "end": end_date.strftime("%Y-%m-%d"),
                        },
                        headers={"Authorization": f"Bearer {self.api_key}"} if self.api_key else {}
                    )
                    response.raise_for_status()
                    return self._parse_response(response.json())

                except httpx.HTTPStatusError as e:
                    if attempt < max_retries - 1:
                        delay = retry_delays[attempt]
                        logger.warning(
                            "INE API request failed, retrying",
                            extra={"attempt": attempt + 1, "delay": delay, "error": str(e)}
                        )
                        import asyncio
                        await asyncio.sleep(delay)
                    else:
                        logger.error("INE API request failed after retries", extra={"error": str(e)})
                        raise ExternalDataFetchError(f"INE API failed: {e}") from e

        return []  # Unreachable but satisfies type checker

    def _parse_response(self, data: dict) -> list[INEBuildingPermits]:
        """Parse INE API response into Pydantic models."""
        results = []
        for record in data.get("data", []):
            results.append(INEBuildingPermits(
                date=datetime.fromisoformat(record["date"]),
                permits_count=record["value"],
                region=record.get("region", "Portugal"),
            ))
        return results
```

### Pydantic Models (raglite/external_data/models.py)

```python
"""Pydantic models for external data sources."""
from __future__ import annotations

from datetime import datetime
from pydantic import BaseModel, Field


class INEBuildingPermits(BaseModel):
    """Building permits data from INE."""
    date: datetime
    permits_count: int = Field(ge=0)
    region: str = "Portugal"


class OMIEElectricityPrice(BaseModel):
    """Electricity spot price from OMIE."""
    date: datetime
    price_eur_mwh: float
    market: str = "MIBEL"


class IPMAWeatherData(BaseModel):
    """Weather observation from IPMA."""
    date: datetime
    station_id: str
    temperature_c: float | None = None
    precipitation_mm: float | None = None


class BPstatMortgageLoans(BaseModel):
    """Mortgage loan data from Banco de Portugal."""
    date: datetime
    total_loans_eur: float
    new_loans_eur: float | None = None
```
