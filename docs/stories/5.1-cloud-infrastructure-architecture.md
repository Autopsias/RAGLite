## Acceptance Criteria

✅ AWS selected as cloud provider with account configured
✅ **PRIMARY ARCHITECTURE:** AgentCore Runtime + Self-Hosted Databases on EC2
✅ **FALLBACK ARCHITECTURE:** Lambda + Self-Hosted Databases (if AgentCore unavailable)

### AC4: Cost Optimization Strategy (Updated for Epic 6)

**Target Usage:** 200 accesses/week (~850 requests/month) + Epic 6 external API calls

| Optimization | Implementation | Savings |
|--------------|----------------|---------|
| **Free Tier Leverage** | AgentCore/Lambda free tier covers 100% of compute | $0-5/month |
| **EC2 Spot Instances** | Use Spot for databases (vs on-demand) | ~$5/month (50% off) |

| **EBS Optimization** | gp3 instead of gp2 | ~$1/month (20% cheaper) |
| **Data Transfer Optimization** | VPC endpoints for AWS services (if needed later) | Future savings |

**Total Cost:** $15-20/month (Spot) to $22/month (Reserved) - **includes Epic 6 external data features**

### AC5: Security Architecture

| Security Layer | Implementation | Cost |
|----------------|----------------|------|
| **MCP Server Auth** | AgentCore Identity (SigV4/JWT/OAuth built-in) | Included |
| **Network Isolation** | VPC with private subnets | $0 (free) |
| **Secrets Management** | AWS SSM Parameter Store (standard parameters) | $0 (free) |
| **Encryption at Rest** | EBS encryption (AWS managed keys) | $0 (free) |
| **Encryption in Transit** | TLS 1.3 (AgentCore enforced) | $0 (free) |
| **IAM Roles** | Least-privilege policies per service | $0 (free) |
| **Monitoring** | AgentCore Observability + CloudWatch | $0 (free tier) |
| **Threat Detection** | VPC Flow Logs + GuardDuty (optional future) | Deferred |

**Key Security Patterns:**
- AgentCore automatic session isolation (no manual implementation)
- IAM roles with narrow policies (principle of least privilege)
- No hardcoded secrets (all via SSM Parameter Store)
- EBS volumes encrypted by default

## Technical Notes

### Why AgentCore Over Lambda?

**Both cost ~$0 for compute at 850 req/month, so decision based on:**

| Criteria | AgentCore | Lambda | Winner |
|----------|-----------|--------|--------|
| **MCP-Native** | Yes (built-in) | No (needs wrapper) | AgentCore |
| **Session Isolation** | Automatic | Manual (DynamoDB) | AgentCore |
| **Authentication** | Built-in (SigV4/JWT) | Manual (API Gateway) | AgentCore |
| **Deployment** | Container (same as local) | Container + Web Adapter | AgentCore |
| **Maturity** | New (2025) | Mature (2014+) | Lambda |
| **Community** | Smaller | Larger | Lambda |
| **Cost** | ~$0.01 | ~$0 | **TIE** |

**Decision:** AgentCore wins 4-2 on technical merit, cost is equivalent.

### Database Deployment Rationale

**Why Self-Hosted on EC2 vs Managed Services?**

| Option | Cost (850 req/month) | Reasoning |
|--------|----------------------|-----------|
| **Qdrant Cloud** | $10-15/month | Not justified for 850 req/month |
| **RDS PostgreSQL** | $15-20/month | Overkill for low-traffic MVP |
| **Self-hosted on EC2 Spot** | **$5-10/month** | Right-sized for usage, 50% savings |

**Trade-offs Accepted:**
- EC2 management overhead (patching, monitoring)
- Single instance = single point of failure (acceptable for MVP)
- Manual backups (can add later)

**When to Migrate to Managed DBs:**
- Traffic exceeds 10,000 req/month
- Need multi-AZ high availability
- Team lacks DevOps capacity for EC2 management
