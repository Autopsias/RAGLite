### Completion Notes List

#### Investigation Findings (2025-12-17)

**Primary Hypothesis REFUTED:** EntityMatchMode.ILIKE vs EXACT has no effect on extraction

1. **Root Cause Analysis:**
   - `timeseries_extract.py` uses `ENTITY_FILTERS` dict (line 1569) with `get_entity_exact_match_clause()`
   - This always generates exact SQL: `entity IN ('Portugal', 'PT', ...)`
   - `data_quality/config.py` EntityMatchMode only affects validation checks, NOT data extraction
   - Both ILIKE '%portugal%' and EXACT 'portugal' return identical 144 rows

2. **Actual Root Causes Identified:**
   - **Data Volatility:** Aug-25 spike (60.40) followed by sharp drops (28.60, 17.80) is unpredictable
   - **Insufficient Regressors:** eurostat_electricity has only 9 data points (semi-annual updates)
   - **SUM Aggregation:** 4 duplicate rows per period are summed (gives 4x inflated values)

3. **Actions Taken:**
   - Applied EntityMatchMode.EXACT in config.py (no effect on extraction)
   - Changed regressors from [eurostat_electricity] to [ttf_gas, api2_coal, industrial_production]
   - Neither change improved MASE (remains at 10.04)

4. **Validation Results:**
   | Metric | Before | After | Change |
   |--------|--------|-------|--------|
   | MASE | 10.04 | 10.04 | None |
   | MAPE | 254.60% | 254.60% | None |
   | Pass Rate | 15/20 | 15/20 | None |

5. **Recommendation:**
   - Keep `data_quality_exempt=True` for electricity_cost (already in place)
   - Consider removing electricity_cost from Epic 7 model selection scope
   - Alternative: Investigate Aug-25 data anomaly and potentially exclude as outlier

## Final Resolution (2025-12-17)

### Solution: External-Only REN Data Hub Integration

After investigating multiple approaches, the solution was to **abandon internal Secil electricity data entirely** and use external Portuguese spot prices from REN Data Hub.

### Root Cause Analysis (Deep Dive)

| Issue | Description | Impact |
|-------|-------------|--------|
| **Budget Data Mixed** | "B " prefix periods mixed with actual data | Sign confusion |
| **Entity Contamination** | Brazil, Lebanon, Tunisia data mixed with Portugal | Value variance |
| **Metric Inconsistency** | "Electricity" (old) vs "Electrical Energy" (new) | Different data series |
| **Row Count Variance** | August: 12 rows, Other months: 4 rows | SUM inflates Aug 3x |
| **Sign Flips** | 2023: positive costs, 2024-25: negative credits | Unpredictable patterns |
| **Short History** | Only 20 data points (2024-2025) | Insufficient for forecasting |

### Approaches Tested

| Approach | MAPE | MASE | Status |
|----------|------|------|--------|
| Original (Eurostat regressor, 9 points) | 254.60% | 10.04 | FAIL |
| REN regressor + internal data | 89.20% | 1.95 | FAIL |
| Internal data AVG aggregation | 27.09% | 1.36 | FAIL |
| **External REN only (chosen)** | **16.10%** | **0.16** | **PASS** ✅ |
