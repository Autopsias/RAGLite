### AC6: Regime Change Detection

**Rationale:** Energy crisis (2022 Q4) caused structural break. Models should detect and handle regime changes.

**Implementation:**
```python
def detect_regime_change(
    series: pd.Series,
    threshold: float = 2.5,  # Standard deviations
) -> list[date]:
    """Detect structural breaks in time series.

    Uses CUSUM (Cumulative Sum) algorithm to identify
    points where the series behavior changes significantly.

    Returns list of changepoint dates.
    """
    from scipy.stats import zscore

    # Calculate rolling z-scores
    rolling_mean = series.rolling(window=6).mean()
    rolling_std = series.rolling(window=6).std()
    z_scores = (series - rolling_mean) / rolling_std

    # Find points exceeding threshold
    changepoints = series.index[abs(z_scores) > threshold].tolist()
    return changepoints
```
