## Problem Statement

### Current State: Variable Query Accuracy (22-88%)

| Query Type | Rows | Entity Coverage | Query Works? |
|------------|------|-----------------|--------------|
| EBITDA | 1,771 | 60% | ✅ Excellent |
| Energy | 1,088 | 88% | ❌ SQL routing fails |
| Petcoke | 0 | N/A | ❌ Not recognized |
| Debt | 1,597 | 61% | ⚠️ Mixed |
| Working Capital | 3,362 | 22% | ❌ Wrong entity |

### Root Causes (Five Whys Summary)

- **RC1: No Entity Normalization** → 22-88% entity variance ("PT", "Portugal", "Secil Portugal" = different entities)
- **RC2: No Metric Synonym Expansion** → SQL `WHERE metric ILIKE '%energy%'` misses "Electrical Energy"
- **RC3: Incomplete Domain Vocabulary** → Petcoke classified as UNKNOWN, tables not extracted
- **RC4: No Hierarchical Context** → Child rows lose parent entity context

```python
# 5-minute TTL in-memory cache
_cache: dict[str, Any] = {}
_cache_timestamp: float = 0.0
CACHE_TTL = 300  # 5 minutes

def get_cached_or_fetch():
    if time.time() - _cache_timestamp < CACHE_TTL:
        return _cache
    # Fetch and update cache
```
