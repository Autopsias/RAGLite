## Non-Functional Requirements (All Sub-Stories)

All client fixes must implement:

| NFR | Requirement | Implementation |
|-----|-------------|----------------|
| NFR1 | Retry logic | Exponential backoff: 3 retries at 2s/4s/8s intervals |
| NFR2 | Timeout handling | 30s default, 60s for large files (EU Oil XLSX) |
| NFR3 | Graceful degradation | Return empty list + log warning when API unavailable |
| NFR4 | Rate limiting | Respect API quotas, implement delays if needed |
| NFR5 | Error classification | Distinguish transient (retry) vs permanent (fail fast) errors |

**Standard Retry Implementation:**
```python
from tenacity import retry, stop_after_attempt, wait_exponential, retry_if_exception_type
import httpx

@retry(
    stop=stop_after_attempt(3),
    wait=wait_exponential(multiplier=2, min=2, max=8),
    retry=retry_if_exception_type((httpx.TimeoutException, httpx.ConnectError)),
    reraise=True
)
async def _fetch_with_retry(self, url: str, params: dict | None = None) -> httpx.Response:
    async with httpx.AsyncClient(timeout=self.timeout, follow_redirects=True) as client:
        response = await client.get(url, params=params)
        response.raise_for_status()
        return response
```

### 4. Data Staleness Detection

```python
# Track last successful fetch per source
class DataFreshnessTracker:
    def __init__(self):
        self._last_success: dict[str, datetime] = {}

    def record_success(self, source: str):
        self._last_success[source] = datetime.now()

    def get_staleness(self, source: str) -> timedelta | None:
        if source not in self._last_success:
            return None
        return datetime.now() - self._last_success[source]

    def is_stale(self, source: str, threshold_hours: int = 48) -> bool:
        staleness = self.get_staleness(source)
        return staleness is not None and staleness > timedelta(hours=threshold_hours)
```

### 5. Caching Layer (Post-MVP)

```python
# Simple file-based cache for expensive API calls
import json
from pathlib import Path

class ExternalDataCache:
    def __init__(self, cache_dir: Path = Path(".cache/external_data")):
        self.cache_dir = cache_dir
        self.cache_dir.mkdir(parents=True, exist_ok=True)

    def get(self, key: str, max_age_hours: int = 24) -> dict | None:
        cache_file = self.cache_dir / f"{key}.json"
        if not cache_file.exists():
            return None

        age = datetime.now() - datetime.fromtimestamp(cache_file.stat().st_mtime)
        if age > timedelta(hours=max_age_hours):
            return None

        return json.loads(cache_file.read_text())

    def set(self, key: str, data: dict):
        cache_file = self.cache_dir / f"{key}.json"
        cache_file.write_text(json.dumps(data))
```

### 1. INE (Instituto Nacional de Estatistica) - Minor Issue

**File:** `raglite/external_data/clients/ine.py`

**Status:** ⚠️ Minor Issue - API works but returns 0 records

**Root Cause:**
INE API returns monthly periods like "Setembro de 2025" which are parsed as `2025-09-01`. When filtering with a start_date that isn't the first of the month (e.g., `2025-09-09`), all monthly data is incorrectly excluded.

**Evidence:**
```python
# Period "Setembro de 2025" parses to 2025-09-01
# Filter start_date = 2025-09-09
# Result: 2025-09-01 < 2025-09-09 → EXCLUDED (incorrect!)
```

**API Status (Verified):**
- Endpoint: `https://www.ine.pt/ine/json_indicador/pindica.jsp`
- Response: 200 OK with valid data
- Building Permits (0012096): 225 periods available
- Construction Output (0011845): 226 periods available
- Construction Cost Index (0011750): 297 periods available

**Fix (Option A - First-of-month normalization):**
```python
# In _parse_building_permits(), _parse_construction_output(), _parse_construction_cost_index():
# Change from:
if start_date and record_date < start_date:
    continue

# To:
if start_date and record_date < start_date.replace(day=1):
    continue
```
