## Problem Statement

### Issue 1: MCP Forecasts Were Univariate Only

The MCP `get_financial_forecast` tool was running in **univariate mode** (no external regressors), achieving only ~89% baseline MAPE. The validation script proved that multi-variate forecasting with external regressors achieves **2.05% average MAPE** (97% improvement).

### Issue 2: INE House Price Index Indicator Wrong

INE indicator `0010017` was returning death statistics instead of house price index data. The correct indicator is `0009201`.

### Sub-Story 6.11.1: MCP Multi-Variate Forecasting Interface ✅

**Files Created:**
- `raglite/forecasting/regressor_config.py` - Regressor configuration and auto-selection
- `raglite/forecasting/regressor_fetch.py` - External regressor data fetching

**Files Modified:**
- `raglite/shared/models.py` - Extended ForecastQueryRequest/Response

**New Request Parameters:**
- `use_external_regressors: bool = True` - Enable multi-variate forecasting
- `regressor_names: list[str] | None = None` - Specific regressors (auto-select if None)
- `future_regressor_strategy: str = "constant"` - Future value strategy

**New Response Fields:**
- `regressors_used: list[str] | None` - Regressors used in forecast
- `model_type: str` - Model type (prophet_univariate, prophet_multivariate, ensemble)

### Sub-Story 6.11.2: Auto-Regressor Selection ✅

Regressors are automatically selected based on metric name:
- Financial metrics (revenue, ebitda): euribor_3m, diesel, ttf_gas
- Energy metrics (electricity, thermal): eurostat_electricity, ttf_gas, api2_coal
- Production metrics (volume, capacity): euribor_3m, diesel, ttf_gas
- Unknown metrics: Default to euribor_3m, diesel, ttf_gas

### Sub-Story 6.11.4: Fix INE Indicators ✅

- Fixed HPI indicator: `0010017` → `0009201`
- Building permits indicator confirmed: `0012096` (correct)

### Sub-Story 6.11.6: Intelligent Model Selection ✅

**Files Modified:**
- `raglite/forecasting/regressor_config.py` - Added `select_model_type()` function
- `raglite/shared/models.py` - Added `prefer_accuracy` and `model_selection_reason` fields
- `raglite/main.py` - Integrated auto-selection logic when `model_type="auto"`

**New Request Parameters:**
- `model_type: str = "auto"` - Now defaults to "auto" for intelligent selection
- `prefer_accuracy: bool = False` - Set True to prefer ensemble (slower but potentially more accurate)

**New Response Fields:**
- `model_selection_reason: str | None` - Explanation of why model was selected

**Selection Logic:**
1. If `prefer_accuracy=True` AND ≥3 regressors available → **Ensemble**
2. If high-value financial metric (revenue, ebitda) AND `prefer_accuracy=True` → **Ensemble**
3. If insufficient regressors (<3) → **Prophet** (ensemble needs regressors for ML models)
4. If operational metric (capacity, utilization) → **Prophet** (faster with comparable accuracy)
5. Default → **Prophet** (~21s vs ~78s with comparable accuracy)

**Performance Comparison (Validated):**
- Prophet Multi-Variate: ~2.2% avg MAPE, ~21s per variable
- Ensemble (4 models): ~78s per variable (3.7x slower), similar accuracy
- Ensemble provides robustness through model diversity, not significant accuracy gain

## Usage Examples

### Default Multi-Variate Forecast (Auto-Select Regressors)
```python
request = ForecastQueryRequest(
    metric="revenue",
    periods_ahead=4,
    # use_external_regressors=True by default
)
response = await get_financial_forecast(request)
# Response includes: regressors_used=["euribor_3m", "diesel", "ttf_gas"]
```

### Custom Regressors
```python
request = ForecastQueryRequest(
    metric="electricity_cost",
    periods_ahead=4,
    regressor_names=["eurostat_electricity", "ttf_gas"],
)
```

### Univariate Fallback
```python
request = ForecastQueryRequest(
    metric="revenue",
    periods_ahead=4,
    use_external_regressors=False,  # Disable multi-variate
)
```

### Intelligent Model Selection (Story 6.11.6)
```python
# Default: Auto-selects Prophet (faster)
request = ForecastQueryRequest(
    metric="revenue",
    periods_ahead=4,
    # model_type="auto" by default
    # prefer_accuracy=False by default → Prophet selected
)
response = await get_financial_forecast(request)
# Response: model_type="prophet_multivariate", model_selection_reason="Prophet selected (faster execution ~21s vs ~78s...)"

# High-stakes forecast: Force ensemble for potentially higher accuracy
request = ForecastQueryRequest(
    metric="revenue",
    periods_ahead=4,
    prefer_accuracy=True,  # Accepts ~3.7x slower execution for ensemble
)
response = await get_financial_forecast(request)
# Response: model_type="ensemble", model_selection_reason="High-value financial metric with accuracy preference..."

# Explicit model selection (bypasses auto-selection)
request = ForecastQueryRequest(
    metric="revenue",
    periods_ahead=4,
    model_type="ensemble",  # Force ensemble regardless of prefer_accuracy
)
```
