## Key Learnings

### 1. MASE > MAPE for Volatile Metrics

MAPE penalizes volatile metrics unfairly. MASE (vs naïve baseline) provides better cross-series comparability. The dual-metric approach is essential for financial forecasting.

### 2. External API Integration is 40% of Work

Initial estimate underestimated integration complexity:
- Each API has unique authentication, rate limits, response formats
- Timeout tuning critical (1s → 10s saved 5+ variables)
- Circuit breakers essential for production stability

### 3. Entity Contamination is Silent Killer

Multi-entity data mixing caused 41% MAPE without obvious signals. Entity detection patterns must be built into extraction pipelines from day one.

### 4. Validation Framework Enables Iteration

The unified validation script (Story 6.21) enabled rapid diagnosis:
- Single command validates all 20 variables
- JSON export supports MCP tool integration
- FQS composite score balances MAPE and MASE

### 5. Quality Gate Flexibility Matters

The MASE-only exemption (Story 6.29) prevented false rejections:
- 8 variables would have failed on MAPE alone
- All 8 beat naïve baseline (valuable forecasts)
- Rigid gates miss nuanced accuracy patterns
